# Security Policy

If you believe you have found a security vulnerability in TokenGate, please report it
privately through [GitHub's private vulnerability reporting](https://github.com/tokengate-models/TokenGate/security/advisories/new)
rather than opening a public issue.

Please include a description of the issue, steps to reproduce, and the affected
version or commit. We will acknowledge reports as quickly as we can and keep you
informed as a fix progresses.

Only the latest release and the `main` branch are supported with security fixes.
